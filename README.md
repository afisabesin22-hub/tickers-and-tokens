# Ticker & Token

### Cryptocurrency & Stock Market News Website

Ticker & Token is a responsive financial news and education website developed as part of my Web Design module assignment. The website brings together cryptocurrency news, stock market developments and beginner-friendly financial information in one accessible platform.

The aim of the project is to present financial information in a clear, organised and visually engaging way, making it easier for users to explore market developments and understand key financial concepts.

## Website Features

The website consists of four main pages:

### 1. Home (`index.html`)
The homepage introduces Ticker & Token and provides navigation to the website's main sections. It features a modern financial-themed design, an introduction to the platform and cards highlighting cryptocurrency, stocks and financial education.

### 2. Cryptocurrency News (`crypto.html`)
This page provides selected cryptocurrency news stories covering Bitcoin, digital asset regulation and other developments in the cryptocurrency industry. Articles include brief summaries and external links to the original news sources.

### 3. Stock Market News (`stocks.html`)
The Stock Market page presents financial news and information about global equity markets. It also includes a responsive HTML table comparing major stock market indices, including the S&P 500, Nasdaq-100, Dow Jones and FTSE 100.

### 4. Market Basics (`learn.html`)
This section introduces fundamental financial concepts, including stocks, cryptocurrency, diversification and investment risks. It features a glossary of financial terminology, frequently asked questions and links to educational resources.

## Technologies Used

- **HTML5:** Used to structure the website with semantic elements such as headers, navigation, sections, articles and footers.
- **CSS3:** Used to implement the website's colour scheme, typography, layout and hover transitions.
- **Bootstrap 5:** Used to create responsive layouts, navigation components, cards and tables.
- **Git:** Used for version control, branching and tracking development changes.
- **GitHub:** Used to manage the project repository and maintain a record of development.
- **GitHub Pages:** Used to host and publish the completed website.

## Responsive Design and Accessibility

The website was developed using a mobile-first approach to provide a consistent user experience across desktop, tablet and mobile devices.

Responsive Bootstrap grids allow content to adjust to different screen sizes, while the navigation menu collapses on smaller devices.

Accessibility considerations include semantic HTML5 elements, logical heading structures, descriptive hyperlinks, keyboard navigation, visible focus indicators and readable text contrast.

CSS transitions provide visual feedback when users interact with news cards and links.

## Running the Website Locally

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or another local development server.
4. Alternatively, run `python3 -m http.server 5501` from the project directory.
5. Visit `http://localhost:5501/index.html` in your browser.

No additional build process is required.

## Development Approach and AI Assistance

The project was developed using an iterative approach, beginning with the homepage and progressing through the remaining content pages.

Git was used to manage development through feature branches and descriptive commits, allowing changes to be tracked throughout the project.

ChatGPT was used as an AI-assisted development tool to support website planning, explain HTML and CSS concepts, suggest Bootstrap implementations and troubleshoot technical issues, including local server configuration.

AI-generated suggestions were used as development guidance, with code reviewed, implemented and tested in Visual Studio Code. Further details and screenshots of the AI-assisted workflow are included in the project's Planning & Analysis Sheet.
